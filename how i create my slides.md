# Slide Design Process Documentation

## Orange Groove Cafe Power BI Presentation

This document explains the process used to design and create the presentation slides for the Orange Groove Cafe analytics project.

---

# 1. Planning the Slide Design

The first step was planning the visual style and layout of the slides.

I began by using **Microsoft PowerPoint** to brainstorm and plan how to present the ideas clearly and professionally.
This included:

* Deciding the visual theme
* Choosing layout structure
* Planning where charts and text would appear
* Ensuring consistency across all slides

The goal was to create a clean and modern dashboard-style presentation suitable for a business analytics report.


---

# 2. Creating the Design Using Shapes

After planning the layout, I started designing the slide elements in PowerPoint.

## Steps taken:

* Inserted shapes to create layout sections
* Designed panels for charts and KPIs
* Used rounded rectangles for a modern dashboard look
* Adjusted alignment and spacing for consistency

This allowed me to build a custom dashboard-style background instead of using default templates.

---

# 3. Adding Shadows and Visual Effects

To improve visual appeal and create a professional look:

* Shadows were added to shapes
* Soft edges and depth effects were applied
* Elements were layered to create a “pop-out” dashboard style
* This improved readability and visual hierarchy

The goal was to make charts and visuals stand out clearly.

# 4. Exporting the Design as SVG

Once the design was finalised:

1. The slide design was exported as an **SVG (Scalable Vector Graphic)**.
2. SVG format was chosen because:

   * High quality resolution
   * No loss of clarity
   * Scalable for different screen sizes
   * Professional for dashboard backgrounds

Steps:

* File → Export
* Choose SVG format
* Save design as image

# 5. Using SVG as Background

After exporting:

* The SVG file was inserted back into PowerPoint
* Set as the slide background
* Locked in place to prevent movement
* Charts and graphs were added on top

This ensured:

* Consistent design across slides
* Clean dashboard appearance
* Professional presentation layout

# 6. Adding Charts and Final Content

Finally:

* Power BI charts and graphs were inserted
